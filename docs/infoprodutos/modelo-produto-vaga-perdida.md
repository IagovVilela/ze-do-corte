# Modelo do produto — Vaga Perdida

## Estrutura adotada: 2 pilares + virada

| Bloco | Função |
|--------|--------|
| **Abertura** | Problema + promessa (linguagem simples) |
| **Pilar 1** | Solução convencional: conta do prejuízo, 5 buracos, 4 passos, scripts |
| **Virada** | “Funciona… mas fazer na mão todo dia é pesado. E se um serviço digital cuidasse disso?” |
| **Pilar 2** | Barbernegon na prática: ponte com cada buraco, prints, **como acessar** (links + cadastro/login) |
| **Fecho** | CTA claro |

## Por que este modelo
Dono de barbearia precisa **entender o método** (senão o software parece propaganda) e **ver o caminho no sistema** (senão o PDF vira só teoria). A virada liga os dois sem vender cedo demais.

## Arquivo
`vaga-perdida-barbernegon.pdf` — gerar com `python3 scripts/build-vaga-perdida-produto-pdf.py`
