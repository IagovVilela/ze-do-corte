# Modelo do produto — Vaga Perdida

## Estrutura adotada: 2 pilares + virada

| Bloco | Função |
|--------|--------|
| **Abertura** | Buraco escondido (vazão) — sem motivação genérica |
| **Diagnóstico** | WhatsApp como métrica falsa + custo duplo do no-show + teste rápido |
| **Pilar 1** | Medição (A−T)×ticket · 5 vazamentos · 4 alavancas · scripts com prazo/fila |
| **Virada** | Método funciona; execução humana é o gargalo (método morre em 3–4 dias) |
| **Pilar 2** | Ponte vazamento→Barbernegon · prints · caminho de acesso (cadastro/login/piloto) |
| **Fecho** | CTA + ordem de configuração |

## Tom do conteúdo
- Mecanismo operacional e números — não slogans (“organize melhor”).
- Scripts com função (compromisso / proteção / encaixe), não “mensagens bonitinhas”.
- Pilar 2 = execução do mesmo problema, não propaganda de app.

## Layout
- Badge de pilar com folga abaixo; títulos usam baseline com ascent (sem sobrepor o badge).
- Cards com altura dinâmica (texto não corta).
