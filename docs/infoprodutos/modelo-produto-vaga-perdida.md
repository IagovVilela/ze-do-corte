# Modelo do produto — Vaga Perdida

## O que o mercado ensina (e o que seu amigo quis dizer)

Infoprodutos de entrada que vendem de verdade **não são “PDF para folhear”**. São **ferramentas embaladas**: o comprador *usa*, não só lê. O preço baixo (R$ 19–97) compra **clareza + ação imediata**, não volume de páginas.

Padrões que se repetem em workbooks / low tickets que performam:

| Pilar | O que significa na prática |
|--------|----------------------------|
| **Uma promessa** | Um problema → um resultado mensurável (ex.: calcular e recuperar vagas em 7 dias) |
| **Ferramenta, não ensaio** | Calculadora, checklist, campos para preencher, scripts copiáveis |
| **Fluxo Assess → Plan → Act → Review** | Diagnosticar → escolher vazadouros → aplicar método → medir de novo |
| **Visual primeiro** | Diagramas, gráficos, prints reais — texto curto ao lado |
| **Sensação de produto** | Progresso, persistência local, copy buttons, etapas numeradas |
| **Ponte comercial honesta** | O software (Barbernegon) aparece como *como executar*, não como “anúncio no final” |

Frase do amigo traduzida: *não vender a festa do PDF — vender um produto construído*.

## Como o Vaga Perdida fica modelado daqui pra frente

### Entrega principal (o produto)
**Experiência web interativa** em `/produtos/vaga-perdida`:
1. Capa com promessa (1 tela)
2. Calculadora ao vivo + gráfico de perda (número que dói)
3. Os 5 vazadouros — marcar os que batem na sua casa
4. Método em 4 passos + scripts com “copiar”
5. Checklist de 7 dias (marcável, salva no aparelho)
6. Tour visual com prints reais do Barbernegon
7. CTA para tirar a agenda do improviso (cadastro)

### Entrega complementar
**Workbook PDF** (impressão / offline): mesmas etapas, campos em branco, menos parágrafo, mais quadro para preencher — *companheiro* da experiência web, não o produto sozinho.

### O que NÃO é mais o centro
- PDF longo de texto corrido
- “Catálogo de prints” sem o dono fazer nada
- Promessa vaga sem calculadora / checklist

## Métrica de sucesso do produto (para você validar)
- O dono consegue **sair com um número em R$** em &lt; 5 minutos
- Marca **pelo menos 1 vazadouro** e **1 dia do checklist**
- Entende *por que* o Barbernegon entra (canal próprio + painel), sem discurso de venda genérico
